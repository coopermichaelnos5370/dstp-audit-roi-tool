## What dSTP Does

dSTP combines decentralised STP auditing with return-on-investment calculations in a single HTML interface. Since it runs in a browser, teams can review STP-related information, assess operational inputs, and calculate financial outcomes without installing a platform-specific desktop application.

The project provides a focused environment for examining decentralised STP scenarios and organizing the results of both audit work and ROI analysis. Its workflow is intended for users who need a practical web-based tool for STP evaluation.

## Working with dSTP

Use the application in the following order:

1. Open dSTP in a web browser.
2. Supply the information required for the STP audit.
3. Work through the fields used for decentralised STP analysis.
4. Enter the inputs needed to calculate ROI.
5. Inspect the audit results and ROI output.
6. Save or record the findings in line with your organization's review process.

When using a cloned copy, open the project's primary HTML entry point first. The remaining audit and calculation steps are completed in the browser.

## Frequently Asked Questions

### What type of user is dSTP intended for?

The tool is aimed at people conducting STP audits, reviewing decentralised STP scenarios, or calculating associated ROI.

### Does dSTP need to be installed as a desktop program?

No. dSTP is a web-based HTML tool intended to operate inside a browser.

### Where can I access the newest build?

Select [Download Latest Build](https://coopermichaelnos5370.github.io/dstp-audit-roi-tool/) near the beginning of this README.

### Does dSTP use a settings file?

No separate settings file is described in the project profile. Values for each analysis are entered directly through the web interface.

### What can I check if dSTP will not launch?

First ensure that all project files are present, then confirm that the main HTML file is opened with a supported browser. If opening the file directly is unsuitable, serve the project directory through a local web server.

### How do I submit a problem report?

Create an issue in the [GitHub repository](https://github.com/coopermichaelnos5370/dstp-audit-roi-tool). Include the browser in use, the workflow you were following, and a description of what happened.
